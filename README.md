# Tic-Tac-Toe-AI
Built an interactive Tic Tac Toe game with an unbeatable AI using the Minimax Algorithm. Developed a simple GUI with Tkinter for real-time gameplay. The AI evaluates all possible moves to always win or force a tie, showcasing recursion, game logic, and decision-making.
